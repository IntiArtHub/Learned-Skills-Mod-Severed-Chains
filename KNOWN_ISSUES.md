# Known Issues

- The standard JAR intentionally has no graphical Skills/mastery screen. Gameplay and progression still work; install the optional Menu Addon for the tracking screen.
- The optional Menu Addon remains a private test kit for the exact Severed Chains `3.0.0-1779-devbuild` engine hash documented in its installer; it is not yet a v1.1 release artifact.
- QoL+, forks, and other modified engines are untested with the standard JAR and are rejected by the Menu Addon installer.
- Steal uses an animation assembled from existing movement and animation primitives rather than introducing a new global movement system.
- Quickchange manual consumption has not yet been retested in the later game section and party-member scenario.
- The final v1.1 icon spacing and Quickchange animation cleanup still need a final visual retest.
