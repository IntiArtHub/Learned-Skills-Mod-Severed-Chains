# Roadmap

- Harden compatibility tests as Severed Chains mod APIs evolve.
- Propose the generic More-menu extension upstream so future releases do not require an engine replacement.
- Add further skills as independent definitions and actions now that Steal, Buff Dance, and Quickchange are implemented in the v1.1.0 candidate.
- Expand mastery presentation after a suitable stock extension surface exists.

This roadmap is directional and does not promise release dates.
